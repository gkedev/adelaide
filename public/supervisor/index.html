Same agent, now supervised.

In AAuth the Supervisor judges every act of the agent (its mission and each purchase) against the mission’s intent and what has happened so far. It is the person by default, or a supervision server the person server hands decisions to. Here the supervision server applies a parent’s standing policy. It can approve, deny, escalate to you, or steer the agent back.
